#  DevSnap — Local-First Developer Snippet & Command Vault

A fast, lightweight developer utility built with React and Vite for storing, tagging, searching, and copying terminal commands and boilerplate code snippets with automatic `localStorage` persistence.

##  Features
- 📋 **One-Click Clipboard Copy**: Instant copy feedback for terminal commands and code blocks.
-  **Dynamic Tag Filtering**: Automatically generates filter pills from your saved snippet tags.
- 🔍 **Real-Time Search**: Filters across both snippet titles and code contents simultaneously.
- 💾 **Zero-Backend Persistence**: Syncs automatically to browser `localStorage`.
